# Case workspace

Mode: Operate.

The first viewport should help a user upload their documents and understand how specialist review works. Octop's familiar chat shell is the pinned visual direction. The signature interaction is selecting a finding and opening its exact document passage, preserving the connection between an agent's interpretation and the evidence.

Important states: no cases, no documents, partial uploads, unsupported file, scanned PDF without extractable text, no topic matches, running task, failed provider call, unconfigured AI, external approval declined, and cited findings. No sample case is presented as actual user data.

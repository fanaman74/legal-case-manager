# Sample files for the converter tests

Real Outlook messages, so the .msg reader is tested on files Outlook wrote:

- `EmailWithAttachments.msg` from [MSGReader](https://github.com/Sicos1977/MSGReader) (MIT licence), test sample files.
- `plain_jpeg_attached.msg` and `plain_uc_unsent.msg` from [Email::Outlook::Message](https://github.com/mvz/email-outlook-message-perl) (Perl licence), test files.

Word, PDF, scanned PDF, image and .eml samples are generated by the tests themselves (tests/samples.py).

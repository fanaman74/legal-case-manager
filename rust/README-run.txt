Case File Manager (Rust version, trial copy)

1. Double-click casefiles.exe. A black window opens and your browser opens
   https://localhost:8444/.
2. The browser warns about the certificate the first time. Choose Advanced,
   then Continue. (The certificate is made for this computer and kept in the
   data folder.)
3. The first time, sign in as "admin" with the temporary password shown in the
   black window. It is also in C:\CaseFiles-rust\data\FIRST-SIGN-IN.txt.
   You'll then choose your own password.
4. Close the black window to stop the app.

Data is kept in C:\CaseFiles-rust\data, apart from the installed app, so
trying this copy never touches your real case files.

What works in this copy: sign-in, people and roles, cases, uploading files
and folders, tags, downloads, case activity and the audit log. Conversion to
Markdown, OCR, search, mailboxes and AI come in the next updates; until then
uploaded files show "Waiting".
